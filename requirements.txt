#
#  TORCH MUST BE A CUDA BUILD.
#  `pip install torch` resolves to a CPU-only wheel, reports success, and then
#  runs every encoder ~5x slower with no error anywhere. If a CPU torch is
#  already installed, `pip install torch` prints "already satisfied" and leaves
#  you on CPU. This is the single most expensive silent failure in the project,
#  so `doctor --gpu` hard-fails when CUDA is absent.
#
#  RTX 50-series (Blackwell) is compute capability sm_120 and needs CUDA 12.8+.
#  This project is verified on the cu130 wheels; cu126 wheels will load but have
#  no sm_120 kernels.
#
#  Recovering from an existing CPU torch:
#    pip install --force-reinstall --no-deps torch==2.12.1+cu130 \
#        --index-url https://download.pytorch.org/whl/cu130
# ─────────────────────────────────────────────────────────────────────────────
